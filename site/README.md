# Camino site (Astro + Tailwind)

Quick start:

1. Change to the site folder:

```bash
cd site
```

2. Install dependencies and run dev server:

```bash
npm install
npm run dev
```

3. Build for production:

```bash
npm run build
npm run preview
```

Notes:
- Copy the `images/` SVG files from the parent project into `site/public/images/` so the gallery displays.
- Recommended hosting: Vercel (first-party Astro support), Netlify, or Cloudflare Pages.
